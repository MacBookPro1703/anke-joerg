# Anke & Jörg

Private Web-App für zwei Personen. Nur Programmcode – alle Inhalte liegen geschützt (Row Level Security) in Supabase.

- `index.html` – die App (eine Datei)
- `sw.js`, `manifest.json`, Icons – Offline-Start, Home-Bildschirm, Push
- `supabase/schema.sql` – Datenbank (einmalig im SQL-Editor)
- `supabase/send-push.ts` – Edge Function für Push-Benachrichtigungen
